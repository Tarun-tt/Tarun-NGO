# Helping India — NGO Website

A responsive React + Vite + Material UI starter for an India-focused nonprofit website.

## Included
- Responsive navigation and mobile drawer
- Hero section, impact statistics, focus areas, featured causes and CTA
- Donation/volunteer dialog with suggested donation amounts
- Responsive layout, accessible labels, basic metadata and polished visual styling
- Demo notice so no real donation is falsely implied

## Run locally

Requirements: Node.js 18+ recommended.

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
npm run preview
```

## Before publishing
- Replace the illustrative impact numbers with verified, current data.
- Use only images you have permission to publish and consider hosting them locally.
- Add the NGO's legal name, registration details, address, privacy policy and contact details.
- Connect the form to a backend and a compliant payment gateway; the current UI does not process donations or send messages.
- Add verified tax-exemption/FCRA information only if applicable and valid.
